# Architectural CAD work

This repository also hosts the West Lake bedroom elevation deliverables. For that
workflow, read `CAD_CONVENTIONS.md`, then these project-local skills:

- `.agents/skills/cad-drawings/SKILL.md`: inspect, measure, compare and render CAD files.
- `.agents/skills/interior-elevation-detailing/SKILL.md`: source-backed interior
  elevations, native CAD objects, cabinet sections and construction-detail review.

These are local skills, not a connection to the user's desktop AutoCAD. Use the
existing checkout; do not create a Git worktree unless the user requests one.
Never overwrite uploaded source drawings. Existing R03 files are review drawings;
installing these skills does not upgrade those files or establish constructability.

The user has requested installation of useful CAD skills and their dependencies.
Do not ask again for those routine installation steps. Use the project conventions
and the user's existing all-bedroom scope rather than repeating preference questions.
Any proposed vertical or fabrication dimensions must remain explicitly identified.
