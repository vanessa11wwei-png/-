## 打开与打印

- `bedroom_elevations_R04.dwg`：AutoCAD 2013格式，含27个图纸空间布局，单位mm。
- `bedroom_elevations_R04.dxf`：保留原生对象的可编辑交换文件。
- `bedroom_elevations_R04.pdf`：27页矢量审阅图，书签可跳转各张。
- DWG中模型与节点按毫米1:1绘制，布局按1:20、1:25或各节点注明比例出图。
  未确认的门窗竖向为U占位，未知净高省略，不能据其图形量取现场尺寸。
- 打印使用相应A3布局、纸张1:1；PDF打印选择“实际大小”，不要再缩放适合页面。
- 中文字体位于`fonts`，附授权文件。安装字体后重开CAD；也可将CN文字样式替换为本机可用中文字体。

## 尺寸和材质状态

P为原图尺寸或可回查几何；I为效果图可见意向；D为新增设计建议；U为缺少可靠依据。
原生尺寸自动读取几何值，D尺寸显示`[D]`，未手写覆盖数字；这不代表所有轮廓与尺寸建立了完整CAD关联约束。

四间吊顶完成净高、门窗竖向及部分分格、材料样板、门套邻柜20余量、桌面与窗台150高差、厂家固定及承载尚未确认。
照片中的织物感、木色及哑光质感不能确认实际品牌、木种、涂料或基材；见材料表中I/D/U的区分。
本版是深化审阅稿，不能直接作为未经现场复尺、选型和签审的施工或下料文件。
